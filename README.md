## 🚀 Featured Projects

### FR-SLAM

A LiDAR-Inertial SLAM system developed in C++ and ROS 2.

Main components:

- LiDAR-Inertial Odometry
- Iterated Error-State Kalman Filter
- Scan-to-Local-Map Registration
- Ground Structural Constraint
- Wall / Heading Constraint
- Loop Closure Detection
- Pose Graph Optimization
- GPU-accelerated modules

Repository:

[FR_SLAM](https://github.com/Fanxu2002/FR_SLAM)
